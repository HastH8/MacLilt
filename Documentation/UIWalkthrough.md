# Onboarding and UI walkthrough

The onboarding uses one stable 820 × 560-point window so page transitions never resize the surface. Its static violet/blue ambient field is strongest in onboarding and contains no idle animation. Content pages use centered hierarchy or a consistent explanation-and-demo split derived from the supplied video’s pacing, without copying its identity or wording.

1. **Welcome** — a compact glass symbol, product name, and one-line purpose.
2. **Screenshot → Paste** — an original desktop mockup, selection region, pointer, and copied confirmation.
3. **Window Switcher** — three distinct window cards with a stable selected state.
4. **Clipboard History** — representative text, image, and file-reference rows.
5. **Feature controls** — aligned lifecycle toggles for each primary feature.
6. **Permissions** — plain-language reasons and deliberate Review buttons; skipping remains available.
7. **Ready** — menu-bar handoff and the active default shortcuts.

The menu-bar panel is intentionally denser and quieter than onboarding. It provides working screenshot, clipboard, switcher, window-layout, and Finder actions alongside onboarding, Settings, and Quit. Settings uses the same dark ambient glass system and separates general behavior, feature lifecycle and storage controls, shortcuts, permissions, and product information.
